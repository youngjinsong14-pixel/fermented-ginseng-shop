# 발효홍삼 쇼핑몰

프리미엄 6년근 발효홍삼 전자상거래 시스템

## 기술 스택

### Backend
- Python 3.12
- Django 5.0
- PostgreSQL
- Django REST Framework
- Wagtail CMS

### Frontend
- Next.js 16
- React 19
- TypeScript
- Tailwind CSS

## 실행 방법

### Backend
```bash
cd backend
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

## 기능
- 제품 관리
- 장바구니
- 주문/결제
- 관리자 대시보드
- REST API
